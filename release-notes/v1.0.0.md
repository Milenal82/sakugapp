# Sakugapp 1.0.0

首个正式版本候选，延续已经测试的 0.5.0 功能。应用名称 **Sakugapp**，包名 **com.sakugapp**，versionName **1.0.0**，versionCode **6**。最低 Android 8.0 / API 26。

- Kotlin、Compose、Material 3 原生界面，支持深色/浅色背景及 English、日本語、繁體中文。
- 两列长方形预览，显示官网真实缩略图、黄色版权标签、紫色动画师标签及 Score；支持标签搜索、组合指令、搜索历史、分页去重与错误重试。
- 原生详情、带边框标签、动画师 Wiki 入口；Media3 播放、倍速、全屏、静音、循环、画面调整和截图分享。
- 原视频通过系统“另存为”下载，提供进度、取消及失败状态。
- 严格帧索引分析使用真实解码索引，不用 FPS/时间跳转冒充逐帧。
- 登录会话加密保存；Vote、评论和官方 Blog/Forum 页面入口保留。用户已反馈测试版 Vote 正常。

已知限制：严格帧分析要求 Android 9+、设备/格式支持真实帧数与索引解码，原文件 ≤200 MiB、像素 ≤3840×2160；GIF 严格逐帧未实现。下载时需保持详情页开启，不是后台下载服务。动态分页虽按 ID 去重，仍可能因网站插入/删除出现遗漏。完整扩展主题/小游戏等未全部移植。没有使用真实账号执行本轮投票、评论写入或账户资料修改。

Debug 版与正式版使用不同证书，通常不能直接覆盖安装。请先记录必要设置并退出测试版账户，再卸载 Debug 版、安装正式 APK；卸载会删除本地历史、设置和会话。以后正式升级须保持包名及签名证书不变，并递增 versionCode。
