# Sakugapp 1.1.0 开发候选

包名 com.sakugapp，versionCode 7，最低 Android 8.0/API 26。此候选不替换已发布 1.0.0，不创建新的公开 Release。

- 每页 60 条真实帖子，提前加载、进度、失败重试和 ID 去重。
- 滚动时搜索区自动收起/展开，输入时保持显示；底部分隔线。
- 1–4 列可持久保存，默认 2；红色 Score 独立可见，版权黄色、动画师紫色。
- 非标签详情元数据紧凑横排，长来源可复制/打开；评分和评论区域保留布局。
- 简体中文与 Android 官方应用语言机制；保留 English、日本語、繁體中文。未手动选择时系统简中自动简中，其他系统语言回退英文。
- 历史统一折叠入口，最近 50 条、单条删除、清空，仅提交搜索时保存。
- 真实分类的标签联想，300ms 防抖、取消、短期缓存及光标处补全；原始查询条件保持。
- 全屏尊重系统旋转锁，并提供手动旋转；复用播放器以保留进度、暂停、速度、循环和静音。

源码、测试、构建脚本和许可随附；代码 GPL-3.0-only。站点媒体属于各自权利人。保持原 settings_v1、历史、会话和缓存数据格式；正式证书相同且版本递增的 APK 才能覆盖升级。Debug 证书无法覆盖正式版，卸载会删除本地数据。

严格帧索引仍需要 Android 9+、相应解码支持、文件 ≤200 MiB/像素 ≤3840×2160。下载仍需详情页保持开启；实时偏移分页不能保证站点变动时完全无遗漏。完整扩展主题、小游戏等既有待办不在本轮扩展。最终测试范围见对应 Actions 构件和 docs/release-1.1.0.md，不将未运行的用例当作通过。
