# Sakuga Mobile v1.1.0

整合最近三轮开发。包名仍为 `com.sakugapp`，versionCode 为 10，沿用 v1.0.0 的正式签名。

## 浏览与搜索

- Post 连续加载、ID 去重及返回位置恢复；向下滚动隐藏搜索区域，点击展开组合条件、联想和历史。
- 保留 AND / OR / 排除、排序与 Score 快捷项，搜索历史最多 50 条。
- 手机支持 1/2/3/4 列，平板另有 8/12 列；平均色工具计算可见缩略图均色，不提供服务端颜色相似检索。

## 播放器

- 全屏旋转、A–B 循环、帧号与实际索引逐帧分析、0.1×–3× 倍速和音量控制。
- 双指缩放、双击暂停、左右切换当前列表中的帖子，高级控制默认折叠。
- A–B 是时间戳循环；严格帧分析需 API 28+、可索引解码的视频和受支持设备，最多 200 MiB / 3840×2160。时间与帧无法可靠对应时明确提示并从第 1 帧开始。

## 收藏夹

- 本地多收藏夹、详情快速收藏与取消收藏、封面、排序、批量管理及 JSON 导入导出。
- 收藏首页只显示收藏夹，点击进入独立视频列表；管理操作放入紧凑菜单。
- 收藏库沿用原数据库，保留帖子、收藏关系和媒体信息；旧 JSON 仍可合并导入。

## 界面调整

- 详情上一帖、下一帖、下载、原帖、收藏五个图标横向排列；Score 与 Post ID、来源等元数据整合。
- 调整标签、评论和搜索区域，统一深浅主题、Post 浮块、动画和按钮间距；缩略图显示已获取的时长及真实 Score。
- 保留简体中文、繁体中文、英语和日语界面。

同证书旧版直接覆盖安装，建议先导出收藏 JSON。Debug 版需先备份收藏再卸载切换；JSON 不包含设置、历史、账号或媒体。

自动化验证范围和运行记录见源码中的 `docs/release-1.1.0.md`。未重测真实账户的 Vote / 评论写入，尚未覆盖真机及全部 Android 版本/解码器。
