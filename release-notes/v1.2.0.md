# Sakuga Mobile v1.2.0

- 外观设置增加应用字号，范围 75%–125%。文字和部分文字控件内边距即时调整，不改变系统字号、视频比例、图标尺寸或最小触控区域。
- 增加 Post 预览标签垂直间距，范围 0–12 dp；默认 0，保留原有标签内边距。仅调整预览标签行之间的额外距离。
- 两项设置均保存到本地，重启后保留。保留此前的搜索、下载、浏览历史、标签收藏及备注、跨版本收藏备份和界面整理。

版本：`1.2.0 / code 13`，包名 `com.sakugapp`，沿用原正式证书。可覆盖安装同证书的旧正式版。此前 `1.2.1 / code 12` 为未公开的开发版编号；Android 按递增的 versionCode 升级。

安装前建议导出收藏。Debug 与正式版签名不同，切换时需要先备份、卸载旧包，再安装并导入。收藏 JSON 不包含媒体、账户凭据、设置或浏览历史。

界面资源支持八种语言；新增译文未作母语审校。未逐一验证所有实体设备、系统字号组合和厂商解码器。
