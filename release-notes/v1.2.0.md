# Sakuga Mobile 1.2.0 开发候选

versionCode 11，包名 `com.sakugapp`，沿用既有签名。本轮只提供 Actions 测试构建，不创建公开 Release。

- 下载按真实 artist、Source 与 Post ID 命名；URL Source 只取主机名，避免凭据和签名路径进入名称。新旧下载关联兼容，批量同名不会覆盖。
- Posts 顶部支持下拉刷新，保留查询和网格设置；刷新失败保留内容，旧分页响应不会覆盖新结果。
- 增加 Français、Español、Русский、한국어，支持资源与复数检查、持久保存；官网 locale 仍仅 en/ja。新译文尚未经母语审校。
- 手机和平板增加六列，紧凑显示真实 Score，折叠次要标签。
- 本地浏览历史按日期分组，实际进入详情才记录；可关闭、删除和确认清空，最多 500 条或 8 MiB，先淘汰旧记录。
- 独立标签收藏支持原始标签搜索、取消、排序和备注筛选；搜索结果顶部提供书签，详情标签长按提供操作。
- 本地标签备注与收藏状态分离，最多 500 字符 / 8 行，不修改原始标签，不向网站提交。

Room 非破坏性升级，保留原有收藏和设置。收藏备份 version 2 包含标签收藏和备注，可导入旧 version 1；历史、凭据和媒体不导出。旧版应用不保证读取新格式。

检查结果、数据边界与真实截图见 `docs/development-1.2.0.md` 及 Actions 证据报告；未通过的设备行为不列为验收完成。
