# Sakugapp 1.2.0 开发候选

com.sakugapp / versionCode 8 / Android 8.0+。沿用正式证书，候选仅通过开发分支 Actions 提供，不替换 v1.0.0，也不自动合并 main。

- 分层深/浅主题与跟随系统、圆角卡片、可调间距和较慢的集中动画。
- 手机 1–4 列、平板 8/12 列；真实时长/未知状态及红色 Score 叠加在缩略图底部，分类标签在图下。
- Room 本地收藏夹：多对多、封面、排序、批量移动/移除、本地搜索、JSON 导入/导出与安全合并。
- 用户确认后顺序下载收藏夹中尚未缓存的视频：最多 20 个/批、200 MiB/文件、1 GiB 总额。保持页面开启；删除收藏关系保留文件，显式清理私有媒体不影响系统下载。
- 标签中文译文可选显示；维护词典和用户自定义优先覆盖；长按复制/搜索/编辑/删除覆盖；不猜人名、不启用在线翻译。
- 播放器高级控制可折叠：时间戳 A–B、已有 0.1×–3× 九档速度、真实解码帧索引、1–5× 双指缩放和平移、双击播放暂停、结果顺序切帖。

A–B 是 30ms 检查加解码 seek 延迟，非逐帧精确循环。严格分析需 API 28+ 与设备解码支持；只有实际样本 PTS 与解码帧数匹配且起点可靠时，才从播放时间对齐；其他情况提示从第 1 帧开始。主播放器不显示用 FPS 猜测的精确帧号。时长在实际获取之前显示“—”。

收藏 JSON 只含本地快照/译名，不含凭据和视频；同 ID、同名收藏夹安全合并且优先保留现有内容。旧 DataStore、历史、会话和缓存路径兼容；图片及播放器仍共用既有缓存，帧分析缓存新增 400 MiB 上限。

对应源码 ZIP、GPL/第三方完整许可、SHA-256 与公开 APK 验证报告随附。构建会运行 96 项 JVM 单测和 Lint；20 项模拟器验收、截图及实际同证书覆盖安装结果请查看同提交 Actions 构件与草稿 PR。真机、其他系统/编解码器、传感器自动旋转和预测返回尚未全面实测。可选双栏、在线翻译、备注未实现；用户确认功能 2 未提供。
