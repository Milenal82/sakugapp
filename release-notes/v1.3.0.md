# Sakugapp v1.3.0

## 简体中文

- 统一搜索首页、专题发现、个人资料、Favorites 和猜谜入口的圆角浮块，缩减多余留白。
- 个人资料卡更紧凑；头像、昵称及恢复操作保持独立。
- 组合搜索分为标签、日期、排序与评级三个区域，底部固定“应用搜索”。保留原始语法、联想和历史回填。
- 猜谜采用两列四选一答案、柔和反馈和简洁结果页；作品池继续支持最多 30 部已验证作品、均衡抽题及去重。
- 统一默认、薄荷、樱花、琥珀四套配色的深浅外观与选中状态；缩短导航过渡，保留 Posts 滚动时的显示阈值。
- 修复主导航恢复到旧子页面及作品池输入法联想问题。

首次进入正式版的此前开发功能：搜索／Posts／个人资料三入口、本地头像昵称、日期范围搜索、14 个专题入口、网站 Favorites 的 1／2／3 星分类、原画猜谜与作品池、作品及集数浏览、原画师统计；播放器锁定、常驻逐帧、A–B 精确裁剪、按需展开评论，以及可恢复的后台批量下载。

精确裁剪会重新编码，边界精度受设备与格式影响；逐帧索引与估算定位会区分显示。作品集数来自自由文本 Source，统计只代表已采样投稿。网站 Favorites 需要真实登录，与本地收藏夹分开。

使用原正式证书，可覆盖安装 v1.2.2。发布流程核对收藏夹、二级分类、标签备注、历史和设置；附件包含对应源码、SHA-256 和 APK 验证报告。实时账户操作、所有输入法及全部实体设备未作穷尽验证；翻译未经母语审校。

## English

- Unify rounded tool tiles across Search, discovery, Profile, Favorites and quiz setup, with less empty space.
- Compact the local profile card while keeping avatar, nickname and reset actions independent.
- Group combined search into tags, dates, and sorting/rating. Keep Apply search visible, with native syntax, suggestions and history intact.
- Arrange quiz answers in a two-by-two grid with softer feedback and a simpler results screen. Keep the 30-work verified pool, balanced sampling and Post ID deduplication.
- Align Default, Mint, Sakura and Amber palettes across light/dark modes and selection states. Shorten navigation transitions while keeping scroll thresholds.
- Fix restored main tabs landing on old child pages and composing-text lookup in the work pool.

Previously developed features reaching a stable release for the first time: Search/Posts/Profile navigation, local avatars and nicknames, date filters, 14 discovery entries, account-scoped 1/2/3-star website Favorites, the artist quiz and work pool, show/episode browsing, and sampled artist statistics; player locking, inline frame controls, precise A–B clip export, on-demand comments, and a recoverable background batch queue.

Precise export re-encodes and has device/format limits. Decoded frame indices are distinguished from estimates. Episode grouping relies on free-text Sources; statistics describe the sampled posts. Website Favorites require a real account and remain separate from local folders.

Signed with the existing official certificate for upgrades from v1.2.2. The release pipeline checks folders, child classifications, tag notes, history and preferences. Corresponding source, SHA-256 checksums and APK verification are attached. Live account operations, every keyboard and every physical device have not been exhaustively tested. Translations have not had native-speaker review.
