# Sakuga Mobile v1.2.1

- 收藏夹：一级收藏夹支持拖拽排序；夹内新增一层子收藏夹，可将同一帖子分到多个分类。详情页仍只收藏到一级收藏夹。
- 数据：保留旧收藏、顺序、封面和多收藏关系；JSON 备份加入二级分类，继续支持旧格式导入。
- Posts：减少滚动时的页面重组、标签计算与文字布局分配，复用未变化卡片和图片缓存。
- 外观：新增蓝色（青色）和粉色强调色，可搭配深色或浅色背景，并保留字体、间距设置。
- 稳定性：纳入上一轮播放器释放、缓冲和列表资源上限改进。全屏按视频比例旋转，默认仅显示视频，单击切换控制栏。

包名 `com.sakugapp`，版本 `1.2.1 / code 14`，沿用正式证书，可覆盖安装 v1.2.0。升级前建议导出收藏；不要卸载或清除数据。Debug 包与正式签名不同。

下载 APK 后可用 SHA256SUMS.txt 校验；附件包含对应完整源码。逐帧分析仍受 Android 版本/解码器限制，A–B 为时间戳循环。没有对所有真机或长时间使用作保证，验证范围见[版本说明](https://github.com/Milenal82/sakugapp/blob/v1.2.1/docs/release-1.2.1.md)。
