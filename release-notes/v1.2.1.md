# Sakuga Mobile 1.2.1 — 开发版本

versionName `1.2.1`，versionCode `12`，包名 `com.sakugapp`。沿用既有正式签名，不创建公开 Release，也不替换已有发布附件。

## 本轮改动

- 收藏备份使用 `sakugapp.library` / `schemaVersion: 3`，通过独立文件键恢复收藏夹、顺序、封面、多收藏夹关系、标签收藏和独立备注。兼容旧 v1/v2 JSON，默认合并并保留本地备注；导入前预览数量、选择冲突策略，完成后报告新增、跳过和失败数量。文件验证或事务失败时不保留部分导入数据。
- 搜索工具使用统一圆角浮块，保留现有条件、历史和编辑状态，长文字可换行。
- 浏览历史增加日期分组、分隔线和紧凑的数量/记录开关区域；设置按现有功能分组，不更换持久化键。
- README 整理为简体中文、英文、日文，补充导航及当前下载、备份和构建说明。
- 启动图标换为提供的图片，补齐自适应图标与各密度资源。

备份不包含媒体文件、凭据、设置及浏览历史。默认按名称合并同名收藏夹，也可选择保留两份；覆盖本地备注需要明确选择。格式、数量/大小限制和兼容性见[备份说明](../docs/backup-format.md)。

## 安装与验证

相同包名和正式证书签名的版本可覆盖安装；建议先导出收藏。Debug 与正式签名不同，切换前须备份，卸载后安装并导入；卸载会删除未备份的本地数据。

Debug APK：`app/build/outputs/apk/debug/app-debug.apk`。本轮实际检查和未验证事项见[测试记录](../docs/test-report.md)，开发 APK 由 [GitHub Actions](https://github.com/Milenal82/sakugapp/actions) 提供。较早 code 9 候选的测试保留在[历史记录](../docs/release-1.2.1.md)，不能作为 code 12 的测试结果。
