# Sakugapp 1.2.1 — 界面精简

开发测试候选，不修改正式 GitHub Release。

- 详情页五个统一图标：上一帖、下一帖、下载、原帖、收藏。长按查看名称。
- 收藏整合为一个入口；Score、来源、Post ID 统一在可换行元数据栏。
- Post 搜索按需展开，自动聚焦；组合搜索、历史、平均色彩收进展开区。
- 收藏首页只显示收藏夹；导入/导出/新建使用统一描边按钮；夹内复用 Post 卡片，管理操作进入更多菜单。
- 移除 Tags 翻译、词典及缓存和收藏页搜索；保留原始标签颜色和 Post 搜索。简体中文、英文、繁中、日文界面继续支持。
- 精简文字，保留删除确认、必要限制、网络错误和无障碍标签。

包名 `com.sakugapp`，versionName `1.2.1`，versionCode `9`。使用既有正式证书的候选 APK 可覆盖既有同签名版本；Debug 版需先导出 JSON，再卸载 Debug、安装候选并导入。不要卸载同签名旧版以升级。

数据库迁移仅删除旧译名表，保留收藏夹、帖子、关系和媒体信息。旧 JSON 可导入，新 JSON 不再包含译名。逐帧格式/大小限制、离线媒体配额不变。

详情和实际验证结果见 `docs/release-1.2.1.md`。
