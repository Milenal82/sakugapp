## Behavior and boundaries

1. Advanced player typography is scoped to that panel (12–13 sp defaults, still app/system scaled), with smaller spacing, default compact chip visuals, 48 dp touch targets ; inline controls follow the detail scroll and fullscreen controls have their own bounded scroll region. Frame/player/surface/lock algorithms are retained.
2. Precise-only export keeps the existing confirmed A/B range, timestamp gate, source-read-only staging, output frame count/duration checks and separate SAF clip destination. The stream-copy mode, labels and unused WebM writer are removed. Internal remuxing joins already re-encoded tracks; no silent copy fallback. Hardware decoders/encoders still constrain formats and boundary accuracy.
3. No Posts mode chips. Bottom Posts explicitly restores the ordinary snapshot, even on reselection. Search submissions switch to independent result data; clearing the query restores ordinary data. Both grid positions and pagination survive detail navigation.
4. The local profile uses a 68 dp avatar and compact actions. Two independent reset icons have tooltips/accessibility labels; image safety, metadata keys and private storage remain unchanged. Six equal feature tiles separate local folders from website Favorites.
5. Amber light/dark colors use the existing complete Material token factory. Existing palette values and semantic red/error/tag colors are retained.
6. DateRangeFilter validates ISO calendar dates, leap years and ordering; recognizes single dates and two/three-dot closed ranges. Picker output uses the requested `date:start...end`. Only one understood date field is adopted; unsupported/duplicate/negated raw conditions remain editable and block picker replacement, never silently disappear. Clear preserves all other tokens; picker dates use UTC to avoid day shifts. Apply still submits through existing history/navigation.
7. Explore has 14 click-to-load entries. Popular-date ranges use device-local LocalDate at click time, Monday week start, and order:score. Artist/Copyright directories request type 1/3, order date/count, 30/page, max five pages. Every row requires a positive tag ID, matching type, original valid name and nonnegative count; ordering is checked inside each response. New means newest tag IDs, popular means post count, not career debut or artistic merit. Twenty directory pages cache for five minutes. Unknown/unsupported responses produce errors.
8. Website Favorites uses the existing authenticated cookie client and verifies website identity before/after each batch. Queries are `vote:1..3:user` or exact level 1/2/3, 20 posts/page. Each returned post is independently checked with the existing currentVote endpoint; global Score is never interpreted as personal vote. Unsupported membership fails the whole page. This is deliberately slower than trusting unverified search syntax: public/shared throttle gates requests. Account changes/logout clear and cancel state, and successful vote changes invalidate results. Local folders/backups are untouched.
9. Quiz settings are separate prefixed keys in the existing DataStore: count 5/10/20/30/40/50, all/custom mode and up to 20 verified Copyright tags. All mode ignores saved pools. Generation requires a supported video URL, exactly one known Artist, no unknown classifications or excluded tags, selected Copyright membership and an unused Post ID. Three unique distractors come from up to 4096 verified Artist tags in the already bounded classification summary; if fewer than four artists remain, at most two verified Artist-directory pages supplement them before failing. Options are shuffled by exact raw name. At most twelve 100-post metadata requests per round; no mass video preloading. Only the current question owns a muted loop player/cache lease, without Post title/tags. Answers unlock after the first decoded frame; errors permit retry/skip. Scoring locks once per Post, result percentage uses actual answered count. Rotation keeps ViewModel progress; exit cancels loading and releases playback. No leaderboard, timer or persistent scores.
