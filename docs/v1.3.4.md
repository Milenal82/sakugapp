# v1.3.4 候选版

基线：main `e0a9e387471b1dde73330f11ff112dfaa5cffa98`。远端 `dev/v134-ui-polish` 起初与 main 相同，无额外提交。保留现有包名 `com.sakugapp`，候选版本为 1.3.4 / code 19。

## 改动

- 搜索历史用时钟／搜索图标和关键词列表；浏览记录用影片图标，保留缩略图、Post ID、原标签和时间。两者继续使用原来的独立存储、删除和清空操作。
- 删除搜索首页历史与专题入口的重复副标题；中文“历史搜索”改为“搜索历史”。资料页去掉重复来源说明，保留账户来源、权限、采样范围、缓存、安全与错误信息。八种语言保持相同资源键和占位符。
- Posts 搜索结果增加返回、当前查询、清空、重新搜索和标签收藏入口。点击查询编辑，继续使用原有联想、组合搜索、历史与平均颜色工具。退出按钮复用系统返回的同一状态清理逻辑，拒绝过期请求；详情返回仍保留结果及列表位置。
- A–B 模块置于“更多功能”第一个位置，包括区间、A/B、开关、清除、滑块和裁剪。仅移动现有 UI 块，不修改 FrameStepper、解码、时间戳、缓存或导出算法。
- Blog 使用文档图标，Forum 使用独立原创对话图标；保留原始网址与 BrowserActivity。资料页复用此前 `70dd8b8` 已验证的六行及窗口 ≥600dp 双栏实现。底栏同样复用其退出后释放 72dp 的实现，避免每帧改变网格高度；不整批合并旧分支。

主要文件：`MainActivity.kt`、`HomeScreens.kt`、`PersonalScreens.kt`、`VideoPanel.kt`、`MainNavigation.kt`、`SearchResultTool.kt`、图标和中／繁中资源。数据模型、数据库、备份格式、正式签名配置均不改动。

检查时公开最新正式版是 v1.3.0 / code 16，源码开发版 code 18，未发现 v1.3.3 或 v1.3.4 远端标签。CI 再次只读检查实际 Release 列表及版本码，发现冲突直接失败。
