- Combined search has tag conditions, a compact date overview/picker, and collapsible score/order/rating. Apply search stays outside the scrolling content. Drafts, native syntax, autocomplete and history are retained. The dialog measures the real remaining window above the IME, with a separate fixed footer; date selection closes the keyboard.
- Quiz setup shows its scope in one tile. Answers form a two-by-two grid measured to a shared height, with wrapped original names and softer semantic feedback. Progress and results use actual completed answers. Media3 creation, sampling, scoring and pool persistence are unchanged by this refinement.
- Default, Mint, Sakura and Amber share full selection tokens; original brand/Score/Artist/Copyright semantic colors are retained. Theme and preference keys are unchanged.
- Native Compose navigation fades use 180 ms, scroll chrome 200 ms. Compose follows the system animation duration scale. The existing 64/28 dp scroll thresholds stay in place; scrolling does not update visibility for every pixel. Main navigation explicitly lands at its root after restoring a saved child stack.

## Checks and evidence

Required local commands are resource checking, Debug tests/Lint/APK, Release tests/Lint and explicitly unsigned preflight. An unsigned preflight is not an installable official APK. Signing remains exclusively in the existing `release-signing` environment, with a pinned SHA-256 certificate and no Debug fallback.

`refinement.yml` runs native fixture tests on API 28 phone and API 35 tablet, including 24 palette/background/font combinations per device. It retains original screenshots and bounded XML summaries at [evidence/v130](https://github.com/Milenal82/sakugapp/tree/evidence/v130). These reports carry the exact source SHA and actual outcomes. The existing `android.yml` full checks and main maintenance workflow remain enabled and are also required by the v1.3.0 publisher; tests are not disabled to make publication pass.

Official publication requires both workflows to pass for the exact release source, Release tests/Lint, official certificate/metadata/checksum validation, and an actual `adb install -r` upgrade from the public v1.2.2 APK. The independent native UI helper imports the old app's normal v4 backup and compares folders, positions, covers, all memberships, children, tag favorites and notes after upgrade; it checks old/new history and retained preferences without private-data injection, uninstall or data clearing. A new local nickname is additionally checked after a force-stop/restart. v1.2.2 had no local avatar/nickname feature, so it cannot seed those fields before upgrade. Existing avatar-copy and independent-reset tests cover the local profile store.

The official workflow first uploads a verified draft bundle, then publishes only after all gates. Unknown versions have no implicit v1.0.0 upgrade fallback. Earlier tags and public assets are not modified.

## Limits

The signed APK remains at the immutable tag `37f5b5515d776ecc53ad8590f14395bb7704bddb`. A later validator-only revision repairs native popup selectors and waits for the platform IME back-callback handoff. Publication requires a strict file allowlist proving no APK inputs or existing Android/maintenance checks changed, passing CI on that validator revision, and a real upgrade using the original signed bytes. The upgrade report records both revisions. No signing key, tag, APK bytes or old public assets are replaced.

- Fixtures and native emulator interaction do not establish live account login or website Favorites correctness for every server deployment. Protected operations have HTTP/parser/state tests and identity validation; real-account review remains needed.
- Live site checks can be blocked by cloud proxy/network policy. HTTP errors remain visible; no alternate host or access bypass is used.
- Sources are free text; episode grouping and artist statistics are explicitly sampled. Custom quiz sampling is finite and may find too few eligible unique clips.
- Actual frame indices and estimated positions are distinguished. A–B playback has decoder latency, and precise export re-encodes with device/format-dependent boundaries.
- Emulator layout checks do not cover every physical GPU, decoder, keyboard or accessibility configuration. Eight locales have resource/format checks, without native-speaker review.

Actual final counts, signed APK properties, upgrade outcome and publication status must be read from matching CI artifacts and the final delivery report; this document does not mark an unexecuted gate as passed.
