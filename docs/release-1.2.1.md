# Sakuga Mobile v1.2.1

包名 `com.sakugapp`，versionName `1.2.1`，versionCode `14`。使用原正式签名；不移动旧标签或替换旧附件。基线包含 v1.2.0 及 `7304de4` 的播放器资源与全屏改动。

- 一级收藏夹通过排序管理中的长按手柄拖动，或上下按钮排序；沿用原 position 和 ID，新建项追加。
- 只有一级收藏夹内部提供二级分类；同帖可在同一父级下多分类。详情收藏选择器仍仅列出一级收藏夹。子分类删除/移除不删除父级收藏。
- Room 3→4 只新增两张表与索引。复合外键约束分类的父级收藏关系，取消该父级收藏时自动清理分类；其他父级关系保留。没有清库或 destructive migration。
- 备份升级为 schemaVersion 4，包含子分类的独立文件键；继续兼容 version 1/2 和 schemaVersion 3，使用事务合并。见[格式说明](backup-format.md)。
- 蓝色（青色）与粉色强调色独立于系统/深/浅背景；旧主题、字体、间距、语言与历史键保持不变。

## Posts 性能范围

Git 对比确认的额外工作：可见项变化触发整个 PostsScreen 重组，标签重复筛选和 TextStyle 创建、预览标签额外 Column，以及页面状态更新时复制已有卡片数据。现在将可见项观察移入 snapshotFlow，记忆标签/样式/时长合并，保留未变化 Post 的对象；图片改用 AsyncImage，仍使用原图 URL、目标尺寸解析与共享缓存。

保留稳定 Post ID、600 条浏览窗口、分页并发保护和图片/视频缓存上限；没有关闭功能或降低缩略图质量。短程对比在同一 API 28 模拟器分别运行 `7304de4` 与新提交：300 条公开响应中的真实帖子、相同 24 次滑动。为隔离布局，两边都不加载缩略图；这不是网络/图片解码或真机性能保证。真实帧时长见 CI 的 post-scroll-profile 及[证据](https://github.com/Milenal82/sakugapp/blob/evidence/maintenance/report.json)，不虚构改善幅度。

## 验证与升级

必要检查为：本地 Debug/Release 单元测试、Lint、编译；API 28 的旧 schema 迁移、空库备份恢复、拖拽、分类增删改、多父级关系、详情一级选择器、主题持久化及基本播放器操作。详细结果以对应提交的 Actions 报告为准。

发布作业使用既有证书，安装真正公开的 v1.2.0/code 13，经其原生导入器和系统文件选择器建立收藏，再 `adb install -r` 到新 APK。比较两版原生导出的收藏夹、顺序、封面、帖子、关系、标签和独立备注，并检查浅色与换行偏好。此过程不卸载、不清数据、不向私有目录注入数据；仅使用隔离模拟器和已取得的公开帖子样本。

没有真实用户崩溃栈，不能确定其长时间崩溃根因；没有运行数小时压力测试、全部厂商真机、实账号写操作或完整逐帧回归。播放器资源风险改进和边界见[历史记录](player-stability.md)。
